## Project Overview
--- 
**EcoTrack** is an app designed to help users *track their daily carbon footprint* and make a small, sustainable choices that add up to a big impact. It's built using **HTML**, **CSS**, and **JavaScript** - but one day, I want to expand it into a full web platform!
---

## Project Goals
---
- Build a user-friendly dashboard that tracks:
  - 🌿 *Energy use*
  - 🚗 *Transportation Impact*
  - 🍔 *Food consumption patterns*
 - Display personalized reports using:
  - `console.log()` to debug progress  
```
if (carbonScore < 50) {
console.log("Great job staying eco-friendly!"};
} else {
 console.log("Let's find ways to reduce your footpoint!");
}
```
